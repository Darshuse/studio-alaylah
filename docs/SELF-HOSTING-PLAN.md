# خطة الـSelf-Hosting (GPU ذاتي) — الطريق لتكلفة متغيّرة ≈ صفر

> الهدف: نمتلك الموديلات ونشغّلها على GPU بنتحكّم فيه → **تكلفة متغيّرة تقترب من الصفر** + **تحكّم كامل في الجودة** (مفيش مزوّد يغيّرها أو كوتة توقفنا).

---

## 1) الفكرة ببساطة
بدل ما نستدعي Together/ElevenLabs (وندفع لكل نداء)، **نشغّل الموديلات المفتوحة بنفسنا**:
- **الأفاتار/تعديل الصور:** Qwen-Image-Edit (Apache 2.0)
- **صور المشاهد:** FLUX.1-schnell / Qwen-Image (Apache 2.0)
- **الصوت:** Chatterbox / Spark-TTS سعودي (MIT/Apache)

كل واحد نغلّفه في **خدمة استنتاج صغيرة** (HTTP)، ونضيف `SelfHostedImageProvider` / `SelfHostedTtsProvider` **بنفس الـinterface الموجود** → يتوصّل للـ`ProviderChain` كنِدّ أو primary. **مفيش إعادة كتابة** — التجريد اللي بنيناه بيخلّيه plug-in نظيف.

---

## 2) وين يعيش الـGPU؟ (3 خيارات — بالترتيب)

### أ) Serverless GPU — **ابدأ هنا** ✅
منصّات: **RunPod Serverless · Modal · Replicate · fal.ai · Beam · HF Endpoints**
- تنشر الموديل، و**يتوسّع لصفر وقت الخمول** (تدفع بالثانية وقت التوليد بس).
- **مفيش تكلفة خمول**، مفيش سيرفر تديره 24/7.
- الأنسب للبداية: تكلفة قريبة من صفر ثابت، وأرخص من الـAPI التجاري، وتتحكّم في الموديل/الجودة.
- عيب: **cold start** (تحميل الموديل 10–30ث) — نخفّفه بـkeep-warm/min-instances.

### ب) GPU مخصّص دائم — **عند الحجم الثابت**
منصّات: RunPod/Vast.ai/Lambda pods، أو سحابة (AWS g5 / GCP L4 / Azure).
- GPU شغّال دائمًا (~$0.20–0.80/ساعة = **$150–600/شهر**) يولّد **بلا حدود**.
- عند حجم كبير مستقر → **التكلفة المتغيّرة/قصة تقترب من الصفر**.

### ج) هاردوير مملوك — **حجم ضخم/لاحقًا**
تشتري GPU server (RTX 4090/A6000) — capex لمرة، الأرخص عند الحجم الهائل، بس عبء تشغيل أكبر.

---

## 3) مواصفات الـGPU المطلوبة
| الموديل | VRAM | GPU مناسب |
|---|---|---|
| Qwen-Image-Edit / FLUX | 16–24GB | RTX 4090 / A10 / L4 (24GB) / A100 |
| TTS (Chatterbox/Spark) | ~6–8GB | يشارك نفس الكارت أو أصغر |

كارت **24GB واحد** يكفي لموديلات الصور، والصوت يركب معاه أو على كارت أصغر.

---

## 4) كيف يتوصّل بالتطبيق (معماريًا)
```
Spring API → ProviderChain
                ├─ (نِدّ/primary) SelfHostedImageProvider → HTTP → [GPU: Qwen-Edit/FLUX]
                ├─ (fallback) TogetherImageProvider (تجاري)
                └─ ...
```
- نغلّف كل موديل في **FastAPI + الموديل** (أو ComfyUI API / diffusers / vLLM / handler المنصّة).
- endpoints بنفس عقد الـprovider: `generateScene` / `editToAvatar` / `cloneVoice`+`synthesize`.
- نضيفه للسلسلة كنِدّ → **QA gate** يقارن جودته قبل ما نعتمد عليه.

---

## 5) خطة الهجرة (مرحلية، بلا مخاطرة)
| المرحلة | نعمل | النتيجة |
|---|---|---|
| **A — الآن** | APIs تجارية (Together/ElevenLabs) primary | المنتج يشتغل، صفر ops |
| **B — تقييم** | ننشر الموديلات المفتوحة على **Serverless GPU** ونضيفها كنِدّ + نمرّرها على **QA gate** | نتأكد الجودة فعليًا |
| **C — تحويل** | لو الجودة عدّت → self-hosted يبقى **primary** (الأرخص)، التجاري **fallback** | تكلفة تنزل بشدّة + مرونة |
| **D — حجم كبير** | GPU مخصّص/مملوك + autoscaling workers | **تكلفة متغيّرة ≈ صفر** + جودة ثابتة |

---

## 6) مقارنة التكلفة (تقديرية)
| الطريقة | تكلفة/صورة | ثابت شهري | ملاحظة |
|---|---|---|---|
| **API تجاري** (Together) | $0.03 | $0 | بلا ops، رسم لكل نداء للأبد |
| **Serverless GPU** | ~$0.003–0.01 | ~$0 | **3–10× أرخص**، يتوسّع لصفر |
| **GPU مخصّص** | ~$0.001–0.005 (مُطفأة) | $150–600 | الأرخص عند الحجم الثابت |

الصوت مشابه: ElevenLabs $0.17–0.20/1k حرف مقابل **~صفر متغيّر** على GPU ذاتي (بعد التكلفة الثابتة).

---

## 7) التحذيرات الصريحة (متبدأش self-hosting بدري)
1. **عبء MLOps:** نشر، تحديث، مراقبة، cold starts، GPU OOM، إدارة نسخ الموديل.
2. **cold start** على serverless — يحتاج ضبط keep-warm.
3. **الجودة تحتاج تحقّق** (الـQA gate) قبل الاعتماد.
4. **القاعدة:** ابقَ على APIs لحد ما **الحجم يبرّر عبء التشغيل**. self-hosting قرار "عند traction"، مش يوم 1.

---

## 8) نقطة البداية الموصى بها (لما نوصلها)
**RunPod Serverless أو Modal** + (ComfyUI/diffusers للصور) + (حاوية Chatterbox/Spark للصوت):
- تنشر موديل مفتوح كـAPI في يوم–يومين، تدفع بالثانية، يتوسّع لصفر.
- تضيفه لسلسلة المزوّدين كنِدّ، تختبر جودته بالـQA gate، وتحوّله primary لما يثبت.

**الخلاصة:** self-hosting = **تكلفة صفر متغيّر + تحكّم جودة كامل**، بس **ثمنه عبء تشغيل** — نعمله **عند الحجم**، والتجريد الحالي بيخلّيه إضافة نظيفة مش هدم.
