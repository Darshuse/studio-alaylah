# workers/ — عمّال التوليد الثقيل

في **MVP** يعمل العمّال **مدمجين داخل الباك إند** (`api`) كـ `@RabbitListener` تحت وحدة `jobs`،
لتفادي التعقيد المبكر (ADR رقم ٢).

**متى ننفصل؟** عندما يصبح توليد الصور/الفيديو ثقيلًا ويحتاج تحجيمًا مستقلًا (GPU/عدد أكبر من المثيلات):
ننقل مستمعي الطابور إلى تطبيق Spring Boot منفصل هنا يشترك في نفس مكتبة الدومين.

## أنواع المهام
| kind | الوصف | المزوّد |
|------|-------|---------|
| `transcribe`    | تفريغ صوت الأب → نص | Azure Speech / Whisper |
| `scene_image`   | توليد صورة مشهد بهوية ثابتة | Replicate / fal.ai |
| `voice_tts`     | نطق النص بصوت الأب (مؤجّل) | ElevenLabs |
| `assemble_video`| تجميع الفيلم | FFmpeg |
