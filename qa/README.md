# حزمة QA — قياس الجودة بالأرقام (مش بالرأي)

أدوات تقيس أبعاد الجودة الحرجة موضوعيًا. تُستخدم كـ**بوابة جودة** (تعيد التوليد لو نزل عن العتبة) وكـ**اختبار انحدار** قبل تغيير أي موديل.

## التثبيت
```
python -m venv venv && venv/Scripts/pip install -r requirements.txt
```
(CPU كافٍ. أول تشغيل ينزّل الموديلات ~300–500MB.)

## الأدوات
| الأداة | تقيس | الأمر |
|---|---|---|
| `face_sim.py` | تشابه الوش (ثبات الشخصية / ترتيب الموديلات) | `python face_sim.py مرجع.png صورة1.png ...` |
| `transcribe.py` | تفريغ صوت عربي (لدقة النطق) | `python transcribe.py narration.wav small` |
| `voice_sim.py` | تشابه المتحدّث (الصوت المستنسخ ↔ الأب) | `python voice_sim.py أب.mp3 سرد.wav` |

## 📊 نتائج القياس (دورة QA — يوسف والعصفور)
| البُعد | النتيجة | العتبة المقترحة |
|---|---|---|
| **ثبات الشخصية** (أفاتار Kontext ↔ أفاتار Kontext، نفس الطفل) | **~90%** (0.899) | ≥ 0.70 |
| **دقة النطق** (WER بين السرد والقصة) | **97.4%** (خطأ 1/39) | ≥ 95% |
| **تشابه صوت الأب** (المستنسخ ↔ العيّنة) | **95%** (0.954) | ≥ 0.85 |
| ترتيب موديل الأفاتار | Kontext 0.283 مقابل flex 0.129 (2.2×) | — |

## ⚠️ ملاحظة صدق حاسمة: شبه الصورة الحقيقية ↔ الكرتون
- watercolor **0.28** · شبه-واقعي **0.35** · 3D **0.37** — **لا يصل 90% ولن يصل.**
- السبب: نماذج التعرّف مدرّبة على وجوه حقيقية؛ أي تنميط (حتى 3D) يُسقط الرقم.
- **الوعد الصحيح المقيس:** «شخصية ثابتة يتعرّف عليها في كل مشهد» (كرتون↔كرتون ~90%)، **لا** «90% شبه لصورتك».

## الاستخدام كبوابة (لاحقًا)
خدمة QA (Python/FastAPI) تستدعيها الـWorkers بعد التوليد → لو نزل عن العتبة **تعيد التوليد** قبل التسليم → **جودة ثابتة لا تتذبذب**.
